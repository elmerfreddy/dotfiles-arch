# AGENTS.md — dotfiles

Arch Linux + Qtile dotfiles managed with GNU Stow. No build system, no tests, no linter. The only executable source of truth is `install.sh`.

## Core commands

```bash
./install.sh                          # Full install
./install.sh --dry-run --packages     # Simulate package install (safe to run anytime)
./install.sh --packages               # Install all packages (reads packages/*.txt)
./install.sh --packages --only base,desktop  # Selective install
./install.sh --stow                   # Apply symlinks only
./install.sh --verify                 # Post-install health check
./install.sh --uninstall              # Remove all stow symlinks

make help                             # List all make targets
```

`--dry-run` works with any flag combination. Use it to validate changes to `install.sh` or `packages/`.

## Package management

Packages live exclusively in `packages/` — **no top-level `packages.txt`**:
- `packages/base.txt` — shell, CLI tools, editors
- `packages/desktop.txt` — Qtile, Xorg, Thunar, audio, theming
- `packages/dev.txt` — docker, java, mise
- `packages/fonts.txt` — Nerd Fonts, Font Awesome, system fonts

`install.sh` without `--only` concatenates all four files at runtime (sorted glob order). Add new packages to the appropriate category file only — no other file needs updating.

Comments (`#`) and blank lines are stripped by the parser. Inline comments allowed: `package  # reason`.

## Stow modules

Managed modules (hardcoded in `install.sh:49`):

```
alacritty  bat  btop  dunst  fontconfig  git  nvim  picom
qtile  redshift  rofi  thunar  tmux  wallpapers  zsh
```

Each module mirrors `$HOME` structure: `<module>/.config/<app>/` → `~/.config/<app>/`. Exception: `git/` and `zsh/` place dotfiles directly in `$HOME`.

`stow` re-applies as delete-then-create (`stow -D` then `stow`). Idempotent.

## Thunar config quirk

`thunar/.config/Thunar/uca.xml` and `accels.scm` are **auto-regenerated by Thunar GUI** when the user changes shortcuts or custom actions. Unexpected diffs in these files after using Thunar are normal — do not revert.

## Git conventions

Conventional Commits: `feat`, `fix`, `refactor`, `chore`, `docs`. Scope = component (`qtile`, `packages`, `install`, `thunar`, etc.). Subject ≤ 50 chars. One logical change per commit. No pre-commit hooks active.

Remote: `git@github.com:elmerfreddy/dotfiles-arch.git`, branch `main`.

## Personal data

`~/.gitconfig.local` is gitignored (`.local` pattern). Created interactively by `install.sh --stow`. Never commit it.

## Adding a new stow module

1. Create `<module>/<path-relative-to-HOME>/` directory structure
2. Add module name to `STOW_MODULES` array in `install.sh:49`
3. Run `./install.sh --stow` to apply
4. If module needs packages, add them to the appropriate `packages/*.txt`
